# Model Exam – Online Event Booking System

This project implements a simple **Online Event Booking System for Students** and includes documentation for software engineering concepts (use cases, DFDs, architecture, activity diagrams) plus DevOps practices (Git/GitLab workflow) and MLflow usage.

## Contents
- `docs/`
  - `set1_use_case_feasibility_testcases.md`
  - `set2_dfd_architecture_git.md`
  - `set3_activity_arch_mlflow.md`
- `app/`
  - Simple Flask‑based structure with services and data layer.
- `mlflow_demo.py`
  - Example script to log metrics with MLflow for the event booking scenario.

The repository is intended to be pushed to GitHub at:
`https://github.com/SATHIYA-26/Model-Exam.git`.
